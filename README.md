# CampusOS — Frontend

**CampusOS** ("One Platform. Your Entire Campus Life.") — Centralized University Management & Campus Ecosystem Platform built with Next.js (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, TanStack Query, React Hook Form, and Zod.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Configure environment variables:

```bash
cp .env.example .env.local
```

3. Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

```bash
npm run dev     # Start Next.js dev server
npm run build   # Build for production
npm run start   # Start production server
npm run lint    # Run Biome checks
npm run format  # Format code with Biome
```
